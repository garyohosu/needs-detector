# Antigravity運用ルール適用確認

- 指示番号: instruction-2026-08-05-002
- 対象リポジトリ: `garyohosu/needs-detector`
- 対象ブランチ: `main`

## 目的

`.agents/AGENTS.md` に追加された常設運用規約を確認し、今後の作業で適用できる状態にする。

## 実施手順

1. 作業開始前に `git status --short` を実行する。
2. 未コミット変更を勝手に破棄しない。
3. 作業ツリーが安全な状態であることを確認する。
4. `git pull --ff-only origin main` を実行する。
5. `.agents/AGENTS.md` を全文読む。
6. `memo.md`、`DESIGN.md`、`TESTPLAN.md`、`agent-a-design.md` の存在と現在の状態を確認する。
7. 常設運用規約を今後の作業へ適用できるか確認する。
8. 確認結果を `result.md` の末尾へ追記する。
9. `result.md` を含む今回の変更をコミットする。
10. `git push origin main` を実行する。

## result.mdに必ず書く内容

- 状態: `COMPLETED`、`BLOCKED`、`FAILED` のいずれか
- `.agents/AGENTS.md` を読んだこと
- `git pull --ff-only origin main` の結果
- 確認したファイル一覧
- 今後この運用規約に従えるか
- 未解決事項または質問
- commit・pushの成否

## 禁止事項

- この指示では、設計書や実装コードの内容を変更しない。
- 未コミット変更を削除、上書き、stashしない。
- force pushを行わない。
- pushに失敗した状態を完了扱いにしない。

## 完了条件

- `.agents/AGENTS.md` を確認した
- `result.md` に確認結果を追記した
- 変更をコミットした
- `git push origin main` が成功した
